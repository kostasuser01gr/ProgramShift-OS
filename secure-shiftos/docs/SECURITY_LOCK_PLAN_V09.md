# ΠΡΟΓΡΑΜΜΑ.xlsx — ολοκληρωμένο σχέδιο προστασίας

**Κανένα πραγματικό email/Owner δεν αφαιρείται από το παρόν release.** Η επιθεώρηση είναι read-only. Το αρχείο βρίσκεται σήμερα στον προσωπικό εταιρικό OneDrive του κοινού λογαριασμού σταθμού. Οι άνθρωποι που διαθέτουν εκείνα τα credentials μπορούν να δουν ό,τι βλέπει ο λογαριασμός.

## Επαληθευμένα ευρήματα (21/11/2026)

- Στο αρχείο διατηρούνται οι πέντε καταχωρισμένες ταυτότητες Owner (συμπεριλαμβανομένου του κοινόχρηστου λογαριασμού σταθμού).
- Δύο ανώνυμοι σύνδεσμοι `edit` στο Excel, ένας ανώνυμος `edit` στον γονικό φάκελο.
- Το εταιρικό connector δεν προσφέρει μηχανισμό `delete_permission` ή επεξεργασίας Purview labels και δεν επέστρεψε διαθέσιμες ετικέτες.

## Προϋποθέσεις ενός πραγματικά ασφαλούς αποτελέσματος

1. Ασφαλές πλήρες backup του αυθεντικού Excel και έλεγχος history πριν από αλλαγές.
2. Καταγραφή/επιβεβαίωση **όλων** των υπαρχόντων απευθείας email grants. Δεν διαγράφονται ή αλλάζουν κατά τη διαδικασία.
3. Κατάργηση των συνδέσμων **Anyone** μόνο από το αρχείο και τον γονικό φάκελο μέσω `OneDrive → Manage access` από εξουσιοδοτημένο Owner. Δεν είναι κατάργηση παραληπτών email.
4. Έλεγχος διευρυμένων ομάδων/κληρονομικών προσβάσεων και έκθεσης προηγούμενων ιστορικών εκδόσεων.
5. Επειδή ο κοινόχρηστος λογαριασμός παραμένει Owner, χρειάζεται **απομόνωση του εμπιστευτικού πρωτότυπου** σε ιδιωτική εταιρική βιβλιοθήκη SharePoint με εγκεκριμένα προσωπικά identities. Διατήρηση του εταιρικού email ως λογαριασμού, όχι απαραίτητα ως Owner σε αυτή τη δεύτερη εμπιστευτική θέση. Όταν ζητείται αυστηρά διατήρηση και της ιδιοκτησίας, είναι αδύνατο να αποκλειστούν οι χρήστες του ίδιου λογαριασμού μόνο με ACL.
6. IT: έλεγχος άδειας Purview και δυνατότητας `Sensitivity label` με δικαιώματα άνοιγμα/επεξεργασία ανά χρήστη, με co-authoring enabled. Εάν δεν είναι διαθέσιμο, επιλέγουμε named-account permissions χωρίς προαιρετικό Excel file password.
7. Παράλληλες αλλαγές από 2 επιτρεπόμενους λογαριασμούς, άρνηση πρόσβασης σε ακατάλληλο λογαριασμό, έλεγχος πραγματικού preview/download και ιστορικού εκδόσεων.
8. Κωδικός προϊσταμένων του κρυπτογραφημένου backup (AES-256-GCM, `.xlsx.enc`) ορίζεται κατά την εξαγωγή — όχι στο GitHub ή στο Excel tab.

## Τι **δεν** αποτελεί προστασία

- `Protect Sheet/Workbook` ή «κρυφή καρτέλα» δεν προστατεύουν εμπιστευτικά δεδομένα.
- Ένα password prompt στη web εφαρμογή δεν προστατεύει έναν απευθείας σύνδεσμο OneDrive ή το δικαίωμα του λογαριασμού Owner.
- Πρόχειρο κλείδωμα αρχείου με κλασικό Excel open password δεν καλύπτει υποχρεωτικό co-authoring.
- Κωδικός κοινός σε όλους αντί για ατομική ταυτοποίηση δεν μπορεί να τηρήσει πολιτική ατομικών εξουσιοδοτήσεων.

## Συμβατότητα & status

- Κύριο Excel: **όχι ακόμη κλειδωμένο**. Ανοιχτοί ανώνυμοι σύνδεσμοι.
- Εφαρμογή V0.9: read-only προετοιμασία/παρακολούθηση ασφάλειας, χωρίς έκδοση ή αλλαγή grants.
- Επιλογή κωδικού: οι supervisors επιλέγουν κωδικό μόνο για encrypted backups· δεν κοινοποιείται εδώ.
- GitHub / Vercel: προστατευμένο συνθετικό demo μόνο, μέχρι να εγκριθεί η εταιρική εγκατάσταση.
